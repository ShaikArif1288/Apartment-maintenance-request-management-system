# Shaik Arif – Apartment Maintenance Request Management System

FSD mini project using HTML, CSS, JavaScript, Express.js, and MySQL.

## Features
- Dashboard statistics and recent requests
- Resident CRUD
- Maintenance staff CRUD
- Maintenance request CRUD
- Assign staff, update status, and record repair costs

## Setup
1. Open this folder in VS Code.
2. Execute `database/apartment_maintenance.sql` in MySQL Workbench.
3. Copy `.env.example` to `.env` and enter your MySQL password.
4. Open terminal in this project folder and run `npm install`.
5. Run `npm start`.
6. Open `http://localhost:3000` in Chrome.

Do not upload `.env` or `node_modules` to GitHub.
